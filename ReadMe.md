# Task 2: AAPL Stock Price Prediction

## Description
A time-series forecasting project using Yahoo Finance data. It uses a Random Forest Regressor to predict the next day's closing price of Apple Inc. (AAPL) based on historical OHLCV data.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the code to fetch live data and train the model.

## Results
- The model achieved a Mean Absolute Error (MAE) of approximately 4.33.
- Random Forest successfully tracks the overall trend but may lag during high volatility.
