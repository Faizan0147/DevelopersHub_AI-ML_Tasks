# Task 1: Iris Flower Exploratory Data Analysis

## Description
This task involves performing an exploratory data analysis (EDA) on the classic Iris dataset to understand the relationships between different flower features (sepal/petal length and width) and their species.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the script/notebook.

## Key Findings
- Petal dimensions are the most significant discriminators for species classification.
- The Setosa species is easily separable from Versicolor and Virginica.
