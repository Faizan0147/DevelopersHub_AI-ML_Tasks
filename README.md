# Task 6: California House Price Prediction

## Description
Regression analysis on the California Housing dataset. This task compares Linear Regression against Gradient Boosting to predict median house values.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the script to view performance comparisons.

## Results
- Gradient Boosting R² Score: 0.776
- Proved that ensemble methods significantly outperform simple linear models on this dataset.
