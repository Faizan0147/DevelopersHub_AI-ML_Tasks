# Task 3: Heart Disease Prediction

## Description
A binary classification task using the UCI Cleveland Heart Disease dataset. The model predicts the presence of heart disease using clinical features like age, cholesterol, and heart rate.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Execute the notebook to clean the data and train the Logistic Regression model.

## Performance
- Accuracy: 89%
- Key features identified: Major vessels colored by fluoroscopy (ca) and chest pain type (cp).
