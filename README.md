# Task 4: AI Health Assistant (TinyLlama)

## Description
An NLP project utilizing the `TinyLlama-1.1B` model to simulate a medical assistant. It includes safety guardrails to prevent providing dangerous advice regarding surgeries or prescriptions.

## Hardware Note
This task requires a GPU (e.g., NVIDIA T4) or at least 8GB of RAM to run effectively.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the code; the model will download automatically from Hugging Face (no API key required for this public model).
